# 分帳系統 — 需求規格書

**專案名稱：** kai-splitbill
**目標：** 免註冊、多人共享的雲端分帳工具，支援不特定多人以公開連結使用
**技術棧：** Vanilla HTML/CSS/JS + Supabase + Cloudflare Pages（全免費，無後端）
**最後更新：** 2026-04-24

---

## 群組

- 建立群組：輸入活動名稱 → 產生唯一分享連結
- 任何人持連結可進入，無需登入，無角色限制
- 群組可改名
- 分享按鈕：複製邀請碼（6 碼英數）

## 免註冊身份機制（Lazy Identity）

- **進入群組無需選身份**，直接可看所有資料（讀取零摩擦）
- **第一次執行寫入動作時**（新增消費、編輯、刪除、標記已付）才觸發身份選擇
- 身份選擇 UI：底部 sheet，列出現有成員供認領；另有「我是新成員」建立新成員
- 群組尚無成員時：直接顯示「輸入你的名字」
- 選完後：LocalStorage 記錄成員 UUID，下次進入自動帶入
- **可隨時點擊頭像更改身份**（選錯時補救）
- 關聯範圍：
  - ✅ 狀態卡個人概覽（我已付 / 我應付）
  - ✅ 新增消費時付款人預設為自己
  - ✅ 結算頁只顯示自己相關的轉帳待辦
  - ❌ 不追蹤誰建立了某筆消費（無擁有者概念）
  - ❌ 編輯 / 刪除不限制身份（任何人可改任何消費）

## 成員管理

- 新增成員（輸入名字）
- 刪除成員（有消費紀錄者不可刪）
- 每位成員可填收款資訊（單一自由文字欄，如「中信 822-1234567 / LINE Pay Me 連結」）

## 消費記帳

- 欄位：消費項目、金額、日期（預設今天）、付款人（預設自己）、分攤方式、參與者
- **分攤方式 A — 均分（Split Equally）**
  - 一鍵平分，自動處理餘數（差額補入付款人帳目，確保總和精確）
  - 參與者預設全選含付款人，可手動取消
- **分攤方式 B — 自訂金額（Exact Amounts）**
  - 每位參與者手動輸入應付金額
  - 防呆：即時顯示「剩餘 $X 未分配」，總和不等於金額時不允許送出
- 精確度：四捨五入至 0.01
- 可編輯消費（編輯前觸發身份確認）
- 可刪除消費，刪除前跳確認提示（刪除前觸發身份確認）

## 明細列表

- 消費按日期降序排列
- 每筆顯示：項目、金額、付款人、分攤方式、參與人數
- 狀態卡：群組總消費 + 個人概覽（已選身份時顯示我已付 / 我應付）
- 匯出：PDF（列印）、Excel

## 結算

- 演算法：計算各人淨額 → 智慧債務抵銷（A 欠 B、B 欠 C → A 直接付 C）→ 最少轉帳路徑輸出
- 每筆轉帳獨立狀態追蹤：**未付 → 已付**（由欠款方自行標記）
- 每筆轉帳顯示：誰付給誰、金額、收款人的收款資訊
- 可查看歷史結算快照

## UI / UX

- Mobile-first，手機單欄；桌機雙欄並排
- 風格參考：Inter 字體、大圓角卡片、深色 FAB、任務導向版面
- 身份選擇：底部滑出 sheet（含動畫）
- 頭像區塊：顯示當前身份，可點擊更改
